# **Project Standards & SDLC Starter Kit**

โฟลเดอร์นี้รวบรวมเอกสารมาตรฐาน (Standard Operating Procedures - SOP) สำหรับใช้เป็น "หัวเชื้อ" ในการเริ่มโครงการใหม่ทั้งหมด เพื่อให้การทำงานร่วมกับ AI เป็นไปตามมาตรฐาน SDLC สากลและรักษาคุณภาพของซอฟต์แวร์

## **เนื้อหาภายในโฟลเดอร์**

1.  **[STANDARD_DEVELOPMENT_GUIDE_V1.md](./STANDARD_DEVELOPMENT_GUIDE_V1.md):** คู่มือหลักในการพัฒนาซอฟต์แวร์ (Security, Architecture, Development, Verification)
2.  **[SDLC_MAP_V1.md](./SDLC_MAP_V1.md):** แผนผังการทำงานในแต่ละระยะของโครงการ
3.  **[PROJECT_INITIALIZATION_PROMPT.md](./PROJECT_INITIALIZATION_PROMPT.md):** "คาถาเรียก AI" สำหรับเริ่มต้นโปรเจกต์ใหม่
4.  **[DIRECTOR_GOVERNANCE_RULES.md](./DIRECTOR_GOVERNANCE_RULES.md):** กฎเหล็กสำหรับ Project Director (การคุมงาน AI)
5.  **[templates/](./templates/):** โฟลเดอร์เก็บเทมเพลตเอกสารต่างๆ (เช่น Spec, Action Log, Delivery Report)

---
