# **SDLC Standards Blueprint v1.0**

โฟลเดอร์นี้รวบรวมเอกสารมาตรฐานและสคริปต์สำหรับการพัฒนาซอฟต์แวร์ภายใต้การควบคุมของระบบ SDLC (Software Development Life Cycle)

## **เนื้อหาภายในโฟลเดอร์**

1.  **[STANDARD_DEVELOPMENT_GUIDE_V1.md](./STANDARD_DEVELOPMENT_GUIDE_V1.md):** คู่มือหลักในการพัฒนาซอฟต์แวร์ (Security, Architecture, Development, Verification)
2.  **[SDLC_PHASES_STEP_BY_STEP.md](./SDLC_PHASES_STEP_BY_STEP.md):** คู่มือสรุปขั้นตอนการทำงานรายระยะแบบ Step-by-Step (พร้อมชุดคำสั่ง AI)
3.  **[SDLC_MAP_V1.md](./SDLC_MAP_V1.md):** แผนผังการทำงานในแต่ละระยะของโครงการ
4.  **[DIRECTOR_GOVERNANCE_RULES.md](./DIRECTOR_GOVERNANCE_RULES.md):** กฎเหล็กสำหรับ Project Director (การคุมงาน AI)
5.  **[07_QUALITY_GATES_DOD.md](./07_QUALITY_GATES_DOD.md):** เกณฑ์การตรวจรับงาน (Definition of Done) ราย Phase
6.  **[08_PORT_REGISTRY.md](./08_PORT_REGISTRY.md):** บัญชีคุมพอร์ตและสภาพแวดล้อม (ป้องกันพอร์ตชนกัน)
7.  **[09_AI_TROUBLESHOOTING_GUIDE.md](./09_AI_TROUBLESHOOTING_GUIDE.md):** คู่มือแก้ไขสถานการณ์เมื่อ AI ทำงานผิดพลาด
8.  **[PROJECT_INITIALIZATION_PROMPT.md](./PROJECT_INITIALIZATION_PROMPT.md):** "คาถาเรียก AI" สำหรับเริ่มต้นโปรเจกต์ใหม่
9.  **[bootstrap_project.sh](./bootstrap_project.sh):** สคริปต์อัตโนมัติสำหรับขึ้นโครงสร้างโปรเจกต์ใหม่ (One-click Scaffold)
10. **[templates/](./templates/):** โฟลเดอร์เก็บเทมเพลตเอกสารต่างๆ (เช่น Spec, Action Log, Delivery Report)

---
